## 🚀 Featured Project
### [Distributed Uptime Monitor](https://github.com/Notreallyaryann/Distributed-monitor)
A high-availability monitoring system built with **Node.js, BullMQ, Redis, and Docker**. 
- **Auto-Scaling:** Custom Docker-based scaler that manages worker nodes based on queue depth (Spins up at 100 jobs, scales down at 20).
- **Architecture:** Distributed producer/consumer model for maximum fault tolerance.
